## Working rules

- The owner requests keyboard-smash Git commit messages, such as `asjdkfhskdjfh`.

- Keep Frost an application around the supplied garrett-warin/engine runtime; reuse existing transports and engine capabilities.
- Preserve the original custom Frost SVG branding and the explicit no-Google search requirement. Keep upstream attribution in legal/source records.
- Keep browser state, proxy transport, and utility views separated. Render untrusted titles and URLs as text.
- Preserve existing project knowledge, update the relevant index when structure changes, and record material decisions.
- Run meaningful checks and distinguish automated evidence, browser evidence, and unverified compatibility.
- Keep raw evidence under `.project-memory/`. Never retain credentials, tokens, cookies, private keys, or unredacted personal data.
