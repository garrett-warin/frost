# Product intent

Frost gives the owner a coherent browser interface for their supplied browsing engine. The product should make browsing, tab management, search, and recovery understandable without requiring knowledge of the proxy implementation.

The visual identity is an informal handmade winter project: legible, slightly uneven lowercase lettering with small icicle tails, cold charcoal/navy surfaces, flat modestly squared controls, and monospace utility text. The start page focuses on the wordmark, centered search, and horizontal quick links; gradients, decorative cracks, ambient logo/search glow, and marketing footer copy are excluded. It is a browser application, not a marketing landing page or dashboard.

The primary user runs Frost locally or on the authorized Fly deployment and opens sites through the proxy. Useful browser controls and honest error states must remain available when the backend or a website is unavailable. Search choice excludes Google by explicit user preference.

Success means the owner can open a site, manage independent tabs, change search engine, bookmark and revisit pages, use the command palette and settings, and recover from failed navigation without raw engine errors. Universal website compatibility and native operating-system capabilities are not promised.
